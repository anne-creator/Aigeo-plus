Aigeo Plus 当前源码包
打包日期：2026-10-25

本包包含当前工作目录的应用源码、数据库结构、测试、依赖锁文件，以及 Vercel 和 Docker 部署配置。
包含 timeline Word/PDF 导入与确认、薪酬计算与展示、OpenAI 接入、私有云端文件上传等当前功能。

本地运行（Node.js 24.x）：
1. 解压后进入 Aigeo-plus 目录。
2. cp .env.example .env
3. npm ci
4. npm run db:push
5. 如需本地演示账号和项目，运行 npm run db:seed（仅用于本地演示）。
6. npm run dev

部署说明：deploy/README.md。
Vercel 使用 Neon PostgreSQL 和 Private Vercel Blob；专用构建脚本会自动生成 PostgreSQL schema 和 Prisma Client，无需手工修改主 schema。
.env.example 使用本地 SQLite 配置。生产环境请设置独立随机会话密钥、初始管理员密码及自己的 OpenAI API Key。

本包不含实际 .env、生产账号密码、数据库数据、上传附件、Vercel 账号绑定信息、依赖目录和构建缓存。
正式站点现有账号及业务数据位于线上数据库，不会因解压源码自动出现在新环境。
源码中的 seed 演示账号仅供本地测试使用。
