# Aigeo+ · 项目考核系统

项目经理按交付节点提交材料，系统按北京时间截止自动判定延期；AI 审核材料是否与季初约定对得上，不通过的自动按比例扣减季度 KPI 奖。基线报告确认后逐个录入项目 timeline 节点，自动进入每个人右侧的日历和当日 checklist，迟完成超过一周开始扣分。管理员在「薪酬与绩效」看每位项目经理的底薪、月提成、季度 KPI 奖和续约奖；项目经理在「我的收入」看每次晚交、审核不通过让自己少拿多少；负责人领任务、交成果、看工时。另有客户分享页、渠道方登录和会议。规则见 [docs/考核规则说明.md](docs/考核规则说明.md)，开发约定见 [docs/开发约定.md](docs/开发约定.md)。

## 本地运行

```bash
cp .env.example .env
npm install
npm run db:push     # 创建 SQLite 数据库 prisma/dev.db
npm run db:seed     # 写入演示数据（见 prisma/seed.ts 顶部的演示账号）
npm run dev         # http://localhost:3000
```

```bash
npm test            # 规则引擎单元测试
npm run typecheck
```

## Timeline 文件导入

在「项目 → 项目 timeline」上传 Word（.docx）或 PDF，也支持 TXT、Markdown、CSV、TSV。文件最多 15 MB，PDF 最多 80 页，单次最多 200 个节点。

1. 上传后只生成草稿，展示事项、日期和原文依据；项目经理可以补全、改日期、增删节点。
2. 项目经理勾选核对并确认后，首次计划直接进入日历及 PM / 客户横向时间轴。
3. 已有计划时，可以追加或替换未完成节点；确认后提交修改申请，管理员审批前客户仍看到原计划，审批后同步新计划，已完成节点保留。

配置 OpenAI API Key 后使用 AI 理解不同文档结构，PDF 同时提交原始版面用于识别扫描件；可通过 `OPENAI_TIMELINE_MODEL` 单独指定模型。无凭证或服务失败时明确提示使用基础提取。基础提取支持常见表格和明确日期，不能识别的日期留空；无文字的 PDF 会提示配置 AI 或更换文件。识别结果始终需要人工核对，不保证任意文档零遗漏。

上传原文只作为不可信数据解析，不执行其中的指令。未确认草稿不会写入客户可见数据；审批记录保留提取原文和文件名，原文件不作为客户附件公开。

## 项目经理薪酬

依据 2026-10-19《项目经理薪酬规则》：管理员在「薪酬与绩效」查看所有项目，点击经理姓名录入回款和工时；项目经理在「我的收入」查看同一份收入明细。

- 标准项目月提成固定 10%，$2,000 / $3,300 在参考汇率 6.8 下分别为 ¥1,360 / ¥2,244。录入实际人民币回款后以实际金额核算，未确认时明确标为估算。超过 $5,000/月的项目需另行约定，不自动计入标准薪酬。
- 回款按服务月记录；沿用原有排期每服务月 30 天。季度预付款可按多个服务月分摊，分摊尾差保留到分。再次录入为更新该月累计金额，不是追加。未来月份预收款不会全部计入本月提成。
- 底薪按当月工作日平均有效工时为 ¥0 / ¥4,000 / ¥8,000 / ¥12,000；未录工时显示待确认，不使用项目数代替工时。
- 季度满奖为 1 个月提成，效果档位为 100% / 60% / 0，再按交付审核得分扣减。不同月份回款金额不一致时，暂采用本季度实际月提成平均值作为基数；未全部确认回款只作合同估算。效果未知不假设满奖。服务期结束、回款确认且交付审核完成后才能结算；已结算金额固化，回款修改需先撤销结算。
- 续约奖每续约 3 个月奖励 1 个月提成。单独录入新一期签约日、服务开始日、实际服务并回款月数及人民币回款，续约期结束后才可标记发放；签约超过原合同结束后 90 天不符合续约奖。原合同档案登记续约奖金，新一期的交付及月提成在新一期项目档案维护。
- 暂停/终止当服务月提成保留，下个服务月起停发；当季 KPI 停发。离职日期单独记录，账号临时停用不等于离职；已发生月提成及已经结算的 KPI 保留，未结奖金停发。
- 「含奖金的月均参考」是假设达成满奖并续约 3 个月的比较值，不是当月发薪金额；底薪单独计算。

升级现有数据库运行 `npm run db:push`，不需要重新 seed 或 reset。测试使用独立临时 SQLite 数据库，不修改本地客户数据。

## AI 功能（可选）

Timeline 文件识别、交付材料审核和任务整理共用 OpenAI API，使用官方 SDK 的 Responses API 和严格结构化输出。薪酬金额由程序按固定规则计算，不交给模型算账。

1. 在 [OpenAI API 平台](https://platform.openai.com/api-keys) 创建 API Key，并确认 API 账户有可用额度。
2. 在本机 `.env` 中填写 `OPENAI_API_KEY="你的密钥"`，不要发到聊天、放在浏览器代码或提交到 Git。
3. 重启服务，在「管理员 → 系统设置 → OpenAI 连接」点击「测试 OpenAI 连接」。状态「已配置」只表示存在密钥，连接测试成功才表示测试时 API 可用。每次测试会对不同的已配置模型各发起一个小请求，产生少量 API 用量。

默认模型为 `gpt-5.6-sol`，可用 `OPENAI_MODEL` 修改共用模型；`OPENAI_TIMELINE_MODEL`、`OPENAI_REVIEW_MODEL`、`OPENAI_TASK_MODEL` 分别覆盖三个功能。所选模型须支持 Responses、严格结构化输出和 reasoning；Timeline 扫描件识别还需要 PDF 图像输入能力。Timeline / 任务使用 low reasoning，审核使用 medium。

未配置 Key 或调用失败时，Timeline / 任务退回基础提取；扫描 PDF 无法提取文字时提示重试或更换文件。材料审核失败保留待人工审核状态，记录脱敏后的错误。服务不自动重试，也不自动切换供应商。请求使用 `store: false`，密钥只由服务器读取；这并不替代 OpenAI 账户自身的数据保留政策。

## 上线

支持 Vercel + Neon PostgreSQL + 私有 Blob 部署，也提供单实例 Docker 云服务器方案。配置和启动方式见 [deploy/README.md](deploy/README.md)。正式库仅初始化管理员，不导入演示数据。

- 数据库：把 `.env` 的 `DATABASE_URL` 换成 Postgres（如 Neon），`prisma/schema.prisma` 里 `provider = "postgresql"`，再 `npm run db:push`。
- 本地文件存 `uploads/`（`UPLOAD_DIR`）；连接 Vercel Blob 后自动切换到私有云存储，浏览器直接上传大文件，下载沿用业务权限检查。
- 务必改掉 `SESSION_SECRET` 和演示账号密码。
